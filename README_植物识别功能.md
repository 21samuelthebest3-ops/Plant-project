# 植物识别功能说明

## 功能概述
基于 [OpenRouter API](https://openrouter.ai/docs/quickstart) 和 GPT-4o 模型实现的智能植物识别功能。

## 主要特性

### 1. 拍照识别
- 点击"拍照识别"按钮打开摄像头
- 实时预览摄像头画面
- 拍照后自动进行AI识别
- 支持高清摄像头（1280x720）

### 2. 相册选择
- 点击"相册"按钮访问设备相册
- 支持常见图片格式（JPEG、PNG等）
- 选择照片后自动进行AI识别

### 3. AI识别分析
- 使用OpenRouter的GPT-4o模型
- 识别植物名称、类型、特征
- 提供生长习性和养护建议
- 置信度评估和详细分析结果

## 技术实现

### API集成
- **服务提供商**: OpenRouter
- **模型**: OpenAI GPT-4o
- **API密钥**: 已配置
- **端点**: https://openrouter.ai/api/v1/chat/completions

### 功能流程
1. 用户拍照或选择照片
2. 图片转换为base64格式
3. 调用OpenRouter API进行识别
4. 解析AI响应并展示结果
5. 提供完整的植物信息

### 错误处理
- 网络连接检查
- API密钥验证
- 图片格式支持
- 用户友好的错误提示

## 使用方法

### 基本操作
1. 进入"拍照生成"页面
2. 选择"拍照识别"或"相册"
3. 拍摄/选择植物照片
4. 点击"识别分析"按钮
5. 等待AI分析完成
6. 查看详细识别结果

### 注意事项
- 确保网络连接正常
- 照片清晰度越高识别越准确
- 植物主体应占据照片主要部分
- 支持多种植物类型识别
